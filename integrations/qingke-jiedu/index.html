快速开始

git clone git@github.com:qingkelab/qingke-jiedu.git
cd qingke-jiedu
npm install
cp .env.example .env      # 填 DEEPSEEK_API_KEY 或 OPENAI_API_KEY（本机 Ollama 亦可）
npm start                 # 浏览器打开 http://127.0.0.1:4780

质量门禁

npm run check   # oxlint（0 error / 0 warning）+ node:test（单元 + 服务端冒烟）

环境要求

  • Node.js ≥ 20
  • 系统 Chrome（网页截图用，CHROME_PATH 可覆盖）
  • ffmpeg（论文播客合成视频用）；配音默认 edge-tts，配 MINIMAX_API_KEY 可切高保真
  • 生成文案需要真实模型：DeepSeek / OpenAI / 本机 Ollama 任一
🚀 在线使用（浏览器版） GitHub 仓库 使用文档 部署配置（Render）
浏览器版（/web/）把整个应用搬进了浏览器：PDF 转图、文案与标题、arXiv 最新论文检索都能直接用， API key 只存在内存里；受浏览器能力限制，网页整页截图、论文播客视频、公众号凭证同步需要在本机/服务器跑 Node 服务（npm start）。 浏览器版源码在仓库 web/ 目录，与 Node 版共用 src/ 里的取源、切片与提示词模块。
